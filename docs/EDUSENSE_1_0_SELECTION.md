# Выбор из плана Gemini — что делать и на каких моделях

Сохранено рядом с исходником: `docs/EDUSENSE_1_0_GEMINI_PLAN.md`.

## Стек сейчас (важно)

Vanilla JS + FastAPI, **не React / не Framer Motion**.  
Живые предметы: **ОГЭ математика + ОГЭ русский**.  
КИМ не сочиняет ИИ. Этап 2: до ~25.08, запуск сайта+миниапп ориентир 15–16.08.

## Честный разбор блоков Gemini

| Блок | Вердикт | Почему |
|------|---------|--------|
| 1. UI Linear/Vercel + Inter + indigo | **Взять идею премиума, не палитру 1:1** | Мы уже уходили от Inter/фиолетового «AI-кабинета». Фон `#0B0F17` ок. Акцент лучше mint/cyan, не indigo как у всех SaaS. Framer Motion / Tailwind-классы не переносим слепо. |
| 2. Мутатор a*x+b=c + 5 предметов ЕГЭ | **Мутатор — да (мат). 5 предметов — нет до 25.08** | Это и есть «каждому свой». Русский мутировать числами почти нельзя — там пул цельных вариантов. 5 предметов раздует пустой каталог. |
| 2. РНО с новыми числами | **Да, после мутатора** | Уже есть кнопка РНО; добить уникальность слотов. |
| 3. Live-лидерборд + combo | **После запуска, не в волне 15–16** | Вау для демо-урока, но без HTTPS/телефона это игрушка. WebSocket + античит очков — дорого по токенам. |
| 4. ИИ проверка ч.2 + Сократ | **Ч.2 — да как HITL. Сократ — позже** | Совпадает с нашей линией: ИИ не пишет КИМ, проверяет сочинение. Подсказки на экзамене спорны (списывание). |
| 5. Mini App, PDF, прогноз, отчёт родителям | **Mini App — must. PDF/прогноз/родители — после живой ссылки** | Без HTTPS миниаппа нет. PDF 1:1 с бланком ФИПИ — тяжёлый кусок. Отчёт родителям черновик уже был. |

## Рекомендуемый порядок этапа 2 (экономия сильной модели)

### Волна A — до публичной ссылки (15–16) — MUST
1. **Мобилка + HTTPS-хостинг + Telegram Mini App (вход по ссылке)**  
   Модель: сильная на деплой/миниапп (1 сессия), Auto на вёрстку телефона.
2. **Премиум UI без смены стека** (тот же vanilla): шапка, карточки, баннер NEW, читаемость КИМ.  
   Модель: **сильная, 1 волна визуала**. Не ставить Framer/React.
3. **Мутатор только ОГЭ математика (числа/варианты) + раздача «каждому свой»**  
   Модель: **сильная**. Русский: разные цельные варианты из пула, не формулы.

### Волна B — до 25.08
4. РНО: слабые номера + новые параметры (мат) / другой текст слота (рус). Auto+сильная если банк сложный.
5. ИИ-проверка ч.2: JSON критерии → учитель подтверждает. Сильная на промпт/схему, Auto на UI карточки.
6. Прогноз балла на дашборде ученика (простая формула, без LLM). Auto.
7. PDF варианта + ключи (упрощённый, не пиксель-perfect ФИПИ). Сильная если верстка ад.

### Волна C — после 25.08 / не жечь квоту сейчас
- Лидерборд комнаты, combo, фан-ники  
- Сократ-подсказка  
- ЕГЭ + физика/общество/информатика  
- AnnouncementBanner можно крошечным на Auto вместе с UI, не отдельным эпиком

## Модели — шпаргалка

| Задача | Модель |
|--------|--------|
| Визуал «вау» кабинета | сильная, 1 чат, узкое ТЗ |
| Мутатор / каждому свой | сильная |
| Mini App + деплой HTTPS | сильная (деплой), Auto (мелочи) |
| ИИ проверка сочинения HITL | сильная на API+промпт |
| Баннер NEW, прогноз балла, копирайт | Auto |
| Порт, CSS-отступ, баг «кнопка не та» | Auto |
| Лидерборд live | не брать в эти 10 дней |

## Что НЕ делать из этого ТЗ сейчас

- Не ставить React/Framer «потому что в ТЗ».
- Не обещать 5 предметов.
- Не включать ИИ в генерацию условий КИМ (мутатор = параметры, не LLM).
- Не делать лидерборд до того, как класс заходит с телефона.

## Черновик цен (13.08.2026, не оферта)

Помесячно. Учитель и ученик — **разные** подписки.

| Кто | Pro | Pro+ |
|-----|-----|------|
| Учитель | **349 ₽/мес** | **799 ₽/мес** |
| Ученик | **199 ₽/мес** | **499 ₽/мес** |

Бесплатно учителю: попробовать выдачу/сдачу с жёстким лимитом (1 класс, мало работ). Ученик без оплаты — только если учитель выдал работу (вход по коду).

### Учитель Pro 349 — состав и лимит ИИ (черновик)

**Лимит ИИ: месячный, не дневной.**  
Учитель проверяет пачку в воскресенье — дневной кап бесит. Месяц понятен на слайде.

Рекомендация: **40 проверок ч.2 / месяц** (сочинение / изложение / развёрнутое).  
Жёстко: закончились — «лимит месяца, сброс 1-го» или апгрейд на 799.  
Антиабьюз по желанию: не больше **15 в сутки**, чтобы не слить 40 за ночь ботом — но в рекламе говорить только «40 в месяц».

На Яндексе 40 проверок ≈ десятки рублей, не дыра в 349.

**Входит (самое важное, не всё подряд):**
- Классы + выдача ОГЭ мат/рус из банка
- Ученики по коду / QR / миниапп
- Кто сдал / не сдал, смотреть работу, своя оценка и комментарий
- Простая аналитика: где класс сыпется
- ИИ-черновик баллов по критериям — **в пределах 40/мес**, учитель подтверждает

**Не входит (это 799):**
- каждому свой вариант
- безлимит / большой пакет ИИ
- PDF-пакет, отчёты родителям, лидерборд

**Оффер:** «Класс пишет ОГЭ с телефона, ты вечером видишь сдачи — без Excel».

### Учитель Pro+ 799 — обязательно прорыв, иначе незачем

Без прорыва 799 = «чуть больше кнопок». Прорыв:

- **Каждому ученику свой вариант** (анти-ГДЗ / анти-«я уже решал»)
- Работа над ошибками в 1 клик (новые числа/слоты)
- ИИ-проверка сочинения/ч.2, учитель подтверждает
- Отчёт родителям / PDF ключей — бонусом, не ядром

**Оффер:** «Списывать бессмысленно: у каждого свой КИМ, ошибки разбираются сами».

### Ученик Pro 199 — анализ

- Свои результаты, прогресс, прогноз балла («сейчас на 4»)
- История работ, слабые номера
- Без кабинета учителя (сам тренажёр / домашка от репетитора)

### Ученик Pro+ 499

- Всё из 199
- Персональные варианты / РНО себе
- Разбор ошибок подробнее (в т.ч. ИИ по тексту, если платит ученик — лимит)
- Карточка родителям

### Экономика (честно)

349 × 20 учителей ≈ 7000 ₽ — сервер отбивается.  
ИИ на всех дешёвых Pro — риск. Лимит проверок или ИИ только в 799.

199 ученик — объём: 30 учеников = 6000 ₽. Имеет смысл, когда есть самоход без учителя.
