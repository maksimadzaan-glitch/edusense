# EduSense 1.0 — Стратегический план и ТЗ системы

Источник: обдумано с Gemini. Сохранено 13.08.2026. Не реализовывать слепо — см. `docs/EDUSENSE_1_0_SELECTION.md`.

Мы строим высокотехнологичную платформу подготовки к ОГЭ и ЕГЭ (EduSense) с премиальным дизайном, интеграцией нейросети, live-геймификацией и защитой от списывания.

Пожалуйста, изучи архитектуру и последовательно следуй приведенному ниже плану реализации.

---

## 1. Визуальный язык и UI/UX (Linear / Vercel Dark Premium Style)

- **Цветовая палитра:** Глубокий космический фон `#0B0F17`, полупрозрачные карточки Glassmorphic (`bg-slate-900/60`, `border-white/10`, `backdrop-blur-xl`).
- **Акценты:** Electric Indigo (`#6366F1`), Neon Cyan (`#06B6D4`), Emerald (`#10B981`).
- **Анимированный баннер обновлений (`AnnouncementBanner`):**
  - Верхняя плашка над шапкой сайта с легким неоновым градиентным свечением и пульсирующим бейджем `✨ NEW`.
  - Закрытие через `✕` с сохранением состояния в `localStorage`.
- **Типографика и Анимации:**
  - Шрифты 'Inter' / 'Plus Jakarta Sans' для интерфейса и 'JetBrains Mono' для кодов и таймеров.
  - Плавные анимации появления элементов и модалок с использованием Framer Motion.

---

## 2. Параметрический Мутатор (Анти-ГДЗ) и Варианты КИМ

- **Соответствие ФИПИ:** Банк заданий (Postgres Packs) покрывает ОГЭ и ЕГЭ по 5 предметам (Математика, Русский язык, Физика, Обществознание, Информатика).
- **Микро-мутатор (Уникальность для каждого ученика):**
  - Задания хранятся в виде шаблонов с переменными (например: `a*x + b = c`).
  - При входе ученика в тест система генерирует под-версию с его уникальными цифрами, формулировками или вариантами ответов.
  - Система автоматически пересчитывает точный ответ и пошаговое решение под сгенерированные данные.
- **Индивидуальная Работа Над Ошибками (РНО):**
  - Авто-анализ ошибок ученика после сдачи работы.
  - Генерация теста РНО, содержащего ТОЛЬКО те типы заданий, где были ошибки, но с НОВЫМИ сгенерированными числами и условиями.

---

## 3. Live-Геймификация: Таблица Лидеров Комнаты (`RoomLeaderboard`)

- **Формула очков (XP):** `Точность ответов + Бонус за скорость + Combo Streak (🔥 x3)`.
- **Интерфейс лидерборда:**
  - Топ-3 с неоновым подсвечиванием (золото, серебро, бронза) и иконками корон.
  - Плавные анимации обгона позиций участниками в реальном времени (`Framer Motion layout animations`).
  - Фиксированная плашка с текущим местом ученика (`#X из N`) внизу экрана.
- **Анонимный режим:** Опция учителя «Скрыть реальные имена» (авто-раздача фан-ников типа *«Квантовый Лев»*).

---

## 4. Модуль Нейросети (ИИ-Автопилот + Human-in-the-Loop)

- **Проверка развернутой части (Сочинения, Изложения, 2-я часть):**
  - Модуль передает в LLM: условие + критерии ФИПИ + ответы ученика (текст/OCR фото).
  - ИИ подсвечивает орфографические, пунктуационные и логические ошибки.
  - Генерация структурированного JSON с баллами по критериям (К1–К4).
  - Учитель получает предзаполненную карточку и подтверждает/корректирует результат в 1 клик.
- **ИИ-Репетитор в стиле Сократа:**
  - Кнопка *«💡 Дай подсказку»* в карточке задания, дающая наводящий вопрос или правило без прямого ответа.

---

## 5. Инфраструктура и B2C-Магниты

- **Telegram Mini App:** Вход ученика по ссылке в 1 клик с быстрой авторизацией по TG-профилю.
- **Печать PDF:** Генерация печатных вариантов 1:1 с бланками ФИПИ + готовые листы ключей для учителя.
- **Прогноз балла:** Динамический виджет на дашборде ученика (*«Текущий уровень: 19 баллов — Оценка 4»*).
- **Отчет для родителей:** Авто-генерация наглядной карточки с успехами ученика за неделю для мессенджеров.
