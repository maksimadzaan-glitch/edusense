# Технические рамки

- Стек фронтенда: vanilla JS + CSS. React и framer-motion не добавляем — анимации на CSS-транзишенах.
- Официальные КИМ ФИПИ не выдумываем, РешуОГЭ/sdamgia — только визуальный ориентир.
- Часть 2 математики (20–25) не мутируем: тип и текст статические, это осознанное решение.
- Аудио изложений — только учебный TTS, не записи ФИПИ.
- `UNIVERSAL_VARY` и автоген у учителя по умолчанию выключены.
